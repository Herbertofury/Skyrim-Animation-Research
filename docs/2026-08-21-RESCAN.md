# Final Ecosystem Rescan — 2026-08-21

A fresh web sweep was run immediately before GitHub publication. The goal was to find materially useful current tooling not already represented in the August 20 research snapshot, not to pad the catalog with generic animation packs.

## New qualified additions

### convertSAM — ScreenArcherMenu YAML to HKX Pose Converter
- Version: **1.0**
- Updated: **2026-04-12**
- Link: https://www.nexusmods.com/skyrimspecialedition/mods/177216
- Why it earned inclusion: converts ScreenArcherMenu `.yaml` static poses into standard Skyrim `.hkx`, enabling in-game pose creation followed by normal pose-pack deployment. The documented pipeline uses Python/PyYAML, Animation Tools N3-style `zBoneKeys`, and HavokBehaviorPostProcess.
- Caveat: weapon-node rotations may need cleanup; this is a static-pose utility, not a general animation retargeter.

### Apply Impulse
- Version: **1.1.0**
- Updated: **2026-07-03**
- Link: https://www.nexusmods.com/skyrimspecialedition/mods/181584
- How-to: https://www.nexusmods.com/skyrimspecialedition/mods/181584?tab=articles
- Why it earned inclusion: can trigger physical impulse and timed actor rotation at exact animation timestamps through annotation payloads (`ApplyImpulseFFC` / `ApplyRotationFFC`).
- Caveat: runtime physics/rotation is not a substitute for correctly authored HKX root motion.

### Trigger Combat Behaviour (TCB)
- Version: **1.1.1a**
- Updated: **2026-06-05**
- Link: https://www.nexusmods.com/skyrimspecialedition/mods/167256
- How-to: https://www.nexusmods.com/skyrimspecialedition/mods/167256?tab=articles
- Why it earned inclusion: drives paired animations, stagger, i-frames, snap-target and stop-time from HKX annotations; current documentation shows PIE-driven paired-animation triggering through OAR/Behavior Data Injector.

## Payload Interpreter compatibility warning

Payload Interpreter remains powerful and widely depended on:
- Source: https://github.com/D7ry/PayloadInterpreter
- Nexus: https://www.nexusmods.com/skyrimspecialedition/mods/65089

However, 2026 user discussion contains **mixed reports for Skyrim 1.6.1170**, including both working configurations and DLL/version failures. The database therefore labels exact-runtime/file validation as mandatory instead of assuming universal compatibility.

Discussion: https://www.nexusmods.com/skyrimspecialedition/mods/65089?tab=posts

## Search convergence

Additional searches covered Skyrim animation/HKX/Blender/VMD/paired/root-motion/pose/cinematic/modder-resource terms across current GitHub and Nexus results. After the additions above, the remaining results were predominantly:

- tools already cataloged,
- old forks of historical `io_anim_hkx`,
- generic animation replacement packs rather than authoring/conversion utilities,
- legacy tutorials already covered by the migration matrix,
- or teased/unreleased systems without enough current public material to treat as usable tooling.

The curated catalog therefore stops at **75 tools/resources** rather than inflating the list with weaker duplicates.
